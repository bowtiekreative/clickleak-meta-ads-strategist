# Meta Ads Audit Checklist

Mark each item PASS, FAIL or UNKNOWN and write the number behind it.

## A. Measurement
1. Pixel or Conversions API on every destination domain
2. Meta landing page views vs pixel PageViews (gap = pixel missing, blocked or consent-gated)
3. Conversion event (Lead, Contact, Schedule, Donate, Purchase) fires on submit or payment success
4. Event verified in Events Manager, Test Events
5. Form connected to an inbox or CRM (submit a test)
6. UTMs on every ad: utm_source, utm_campaign, utm_content (ad), utm_term (audience)
7. Optimization event matches the business goal
8. No campaign optimizing for an event that has never fired
9. Inbox, forms, payment processor and calendar checked for untracked conversions
10. Zero-result math done: upper bound about 3 / page views

## B. Delivery and structure
11. No unplanned or reactivated campaigns
12. Spend cap on every campaign
13. Frequency per ad set (about 1.0 = no repeat exposure)
14. Retargeting ad set exists (video viewers, site visitors, engagers)
15. Spend by hour: no midnight burst
16. Lifetime budget + ad schedule where buyers keep office hours
17. Spend share vs CTR by country and region
18. Priority geographies have their own ad sets and budgets
19. 3 to 6 ads per ad set
20. Spend share follows CTR, not just cheap CPM
21. Placement CTR on meaningful spend; low performers excluded
22. Audience tiers compared; tight lookalikes from small seeds questioned
23. Age bands with spend and 0 clicks excluded
24. Device split checked (desktop delivery for B2B)
25. Learning phase status per ad set

## C. Creative
26. CTR and CPC by format (video, photo, text, carousel)
27. Spend distribution vs performance by format
28. Each ad classified by angle (testimonial, story, intro, pitch, offer, education)
29. Video hook rate (3 s views / impressions)
30. Video 25 / 50 / 100% retention and average watch time
31. Hook and name in first 3 seconds, captions burned in
32. Static ads show a real person, one short line
33. No creative judged on fewer impressions than the test needs

## D. After the click
34. Load rate = page views / link clicks (under about 80% = slow page)
35. Mobile page speed checked
36. Page headline repeats the ad promise
37. Form asks only what is needed
38. Next step after submit is clear (thank-you page, calendar, email)

## E. Trust
39. Hostile or spam comments hidden
40. Page running the ad matches the ask
